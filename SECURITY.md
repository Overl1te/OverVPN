# Security Policy

## Поддерживаемые версии

Актуальная ветка `main` и последние теги релизов. Старые снапшоты без патчей не поддерживаются.

## Как сообщить об уязвимости

**Не открывайте публичный Issue** для security-находок.

1. Создайте приватный отчёт: [Security Advisories](https://github.com/Overl1te/OverVPN/security/advisories/new)
2. Опишите влияние, шаги воспроизведения и затронутый компонент (API / web / core / install)
3. Не прикладывайте рабочие эксплойты в публичные каналы; PoC — только в advisory

Обычно отвечаем в разумные сроки после получения отчёта. После фикса можно согласовать disclosure.

## Что считается in-scope

- Обход авторизации / привилегий в панели или API
- Утечка секретов подписок, JWT, master keys, бэкапов
- RCE или arbitrary write через control plane
- Подделка/перехват конфигурации data plane из панели

## Out of scope

- Слабости самих протоколов / клиентских приложений сторонних VPN-клиентов
- DDoS против вашей ноды или сети
- Социальная инженерия и физический доступ к серверу
- Issues без минимального сценария воспроизведения

## Жёсткие правила для операторов

- Не коммитьте `.env`, сертификаты, ключи Reality/TLS, Telegram-токены
- После компрометации ноды: смените bootstrap/admin пароли, JWT secrets, master key и перевыпустите подписки

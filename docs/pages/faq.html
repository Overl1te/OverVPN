FAQ

Установка

Не открывается панель после install

  1. overvpn status — контейнеры Up?
  2. overvpn info — правильный URL?
  3. DNS A-запись на IP сервера?
  4. Порты 80/443 открыты?
  5. overvpn logs web и overvpn logs api

Сертификаты Let's Encrypt не выпускаются

  • A-записи резолвятся до выпуска
  • Порт 80 доступен с интернета
  • overvpn config certs или overvpn nginx

Нужна только панель без VPN на этом сервере

overvpn install --no-proxy, затем добавьте удалённые ноды через визард.

Панель и API

Не могу войти

  • Учётка из overvpn info
  • overvpn bootstrap
  • CORS_ORIGINS совпадает с URL панели
  • В проде AUTH_COOKIE_SECURE=true только по HTTPS

502 Bad Gateway

overvpn status  # контейнеры в состоянии Up?
overvpn restart  # перезапуск стека
overvpn logs web  # логи фронтенда за прокси

Прокси-ноды

Агент не становится online

  1. PANEL_URL доступен с ноды
  2. NODE_ID / токен совпадают с записью в панели
  3. С панели доступен AGENT_BASE_URL (порт 7700)
  4. overvpn logs agent на ноде

Как добавить второй сервер

Прокси-ноды: визард → install-proxy.

VPN и ядро

Клиент не подключается

  1. Inbound создан на нужной ноде, apply успешен
  2. Пользователь ACTIVE
  3. Inbound назначен (assignment / план)
  4. UDP/TCP порт открыт в firewall на ноде
  5. Порт inbound совпадает с publish в Compose

Нет inbound'ов после install

Это ожидаемо: default inbounds выключены. Создайте вручную или --create-default-inbounds.

Apply откатывается (rollback)

Смотрите Config в UI и overvpn logs core / overvpn logs agent.

Подписки

429 Too Many Requests

Rate limit. Увеличьте SUB_RATE_LIMIT_* в .env.

Clash не импортирует

Используйте ?format=clash и Clash Meta / Mihomo.

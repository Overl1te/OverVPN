Ручной запуск (Docker)

Если не используете install.sh, поднимите стек через Docker Compose.

1. Конфигурация

cp .env.example .env  # создать локальный конфиг

Замените все REPLACE_*. Секреты генерируйте независимо:

openssl rand -hex 32  # JWT / пароли
openssl rand -hex 32  # SECRETS_MASTER_KEY — ровно 64 hex
openssl rand -base64 36  # пароль владельца (≥ 16 символов)

Profiles в COMPOSE_PROFILES: panel, proxy, singbox / xray / mtproxy, tools. Для co-located по умолчанию: panel,proxy,singbox,xray,mtproxy.

2. Старт

pnpm install  # зависимости монорепо
pnpm compose-up  # поднять стек из GHCR (panel + proxy compose)
pnpm compose-build  # или: собрать образы локально

Команды pnpm compose-* поднимают оба файла: deploy/docker-compose.yml и deploy/docker-compose.proxy.yml.

3. Владелец и локальный прокси

docker compose --env-file .env -f deploy/docker-compose.yml --profile tools run --rm bootstrap-admin
# затем (если нужен локальный ProxyServer + NODE_TOKEN):
docker compose --env-file .env -f deploy/docker-compose.yml --profile tools run --rm \
  -e AGENT_BASE_URL=http://agent:7700 \
  api node apps/api/dist/scripts/bootstrap-local-proxy.js

Либо pnpm bootstrap:admin для владельца без Compose one-shot.

4. Проверка

  • Панель: http://localhost:8080
  • Health: curl -s http://localhost:8080/api/health
  • Агент (если proxy): curl -s http://127.0.0.1:7700/health

5. Остановка

pnpm compose-down  # остановить и удалить контейнеры

Полный список переменных — справочник .env.

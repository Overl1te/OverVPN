Ручной запуск (Docker)

Если не используете install.sh, поднимите стек через Docker Compose.

1. Конфигурация

cp .env.example .env

Замените все REPLACE_*. Секреты генерируйте независимо:

openssl rand -hex 32
openssl rand -hex 32
openssl rand -base64 36

2. Старт

pnpm install
pnpm compose-up
# или: pnpm compose-build

3. Владелец

pnpm bootstrap:admin

4. Проверка

  • Панель: http://localhost:8080
  • Health: curl -s http://localhost:8080/api/health

5. Остановка

pnpm compose-down

Полный список переменных — справочник .env.

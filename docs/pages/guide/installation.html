Установка

Рекомендуемый способ — установщик install.sh на Ubuntu / Debian с доступом root или sudo.

Требования

Требование Пояснение
ОС Ubuntu / Debian (рекомендуется)
Права root или sudo
Порты 80, 443 (TCP), UDP 443 для VPN
DNS A-записи на IP сервера при установке с доменами
Ресурсы Минимум 1 vCPU, 1–2 GB RAM, 10+ GB диск
Подсказка По умолчанию установщик тянет готовые образы из GHCR — сборка на сервере не нужна.

Быстрая установка

curl -fsSL https://raw.githubusercontent.com/Overl1te/OverVPN/main/install.sh -o /tmp/overvpn-install.sh && sudo bash /tmp/overvpn-install.sh @ install  # установка из GHCR

Локальная сборка образов на машине:

curl -fsSL https://raw.githubusercontent.com/Overl1te/OverVPN/main/install.sh -o /tmp/overvpn-install.sh && sudo bash /tmp/overvpn-install.sh @ install --build  # сборка образов на сервере

Мастер установки

Интерактивный мастер — серия консольных экранов (очистка терминала, баннер, рамка с пунктами). Навигация: стрелки ↑/↓ и Enter (цифры — быстрый выбор). Сначала задаются все ответы, затем установка идёт без пауз.

Экран Содержание По умолчанию
Language English / Русский English
Depth Простая или детальная установка Простая (оба ядра + MTProxy)
Mode С доменом (Nginx + TLS) или только IP Домен; IP → http://IP:8000
Hosts Базовый домен, панель, подписки, VPN-хост, email panel. / sub. / vpn. + admin@
DNS Список A-записей; проверить сейчас (ожидание до ~15 мин) или пропустить Проверить
Detailed Протоколы → ядра → пресет/порты → default inbounds → UFW Только в --detailed
Confirm Итог и старт установки Начать

Ядра включаются профилями Compose singbox / xray / mtproxy. Доустановка после install: overvpn enable-core singbox|xray|mtproxy.

После установки выводится экран с URL панели и учётными данными владельца.

Флаги установщика

Флаг Назначение
--simple / --detailed Простой или детальный мастер
--protocols <list> Список протоколов
--cores singbox,xray,mtproxy Ядра (без protocols → все протоколы ядер)
--ports key=value,… Порты протоколов
--create-default-inbounds / --no-default-inbounds Стартовые inbound’ы
--base-domain <host> Базовый домен
--panel <host> Хост панели
--subscription <spec> Хост или путь подписок
--vpn-host <host> VPN-endpoint
--email <email> Let's Encrypt email
--port <port> Порт без домена (8000)
--build Локальная сборка образов
--skip-dns Не ждать DNS
--no-nginx Без Nginx/TLS
--no-ufw Не трогать UFW

После установки

overvpn info  # URL панели и учётные данные
overvpn status  # убедиться, что стек запущен
  1. Откройте URL панели из overvpn info
  2. Войдите логином и паролем владельца
  3. Смените пароль и включите TOTP 2FA

Где лежит установка

По умолчанию /opt/overvpn: .env, .install.conf, .credentials.

Введение

OverVPN — панель-оркестратор (control plane) плюс прокси-ноды (data plane). Панель не маршрутизирует VPN-трафик сама: она хранит желаемое состояние и применяет конфиги на нодах через агент (@overvpn/agent).

Что умеет

Область Возможности
Протоколы Hysteria2, VLESS Reality, Trojan, Shadowsocks, WireGuard, Xray TLS/SS/WireGuard, MTProxy
Панель Пользователи, inbound'ы, планы, прокси-серверы, онлайн-сессии, аудит
Подписки JSON (sing-box), Clash Meta / Mihomo YAML, список ссылок, QR
Учёт Трафик, сроки, лимиты устройств, автоматический enforce
Операции Apply на ноды с rollback, бэкапы панели, Telegram-алерты

Интерфейс панели по умолчанию на русском; в шапке есть переключатель EN/RU.

Архитектура (упрощённо)

1. Администратор → HTTPS → Web-панель → API NestJS
2. API → PostgreSQL, Redis; apply → агент ноды → ядра
3. VPN-клиенты → UDP/TCP → sing-box / Xray / MTProxy на ноде
4. Клиенты подписок → HTTPS → Subscription URL → API

По умолчанию overvpn install ставит панель и локальный прокси на одном хосте (co-located). Удалённые ноды добавляются в разделе Прокси-ноды: визард → install-command → overvpn install-proxy.

Зона Engine Протоколы
Sing-box SING_BOX HYSTERIA2, VLESS_REALITY, TROJAN, SHADOWSOCKS, WIREGUARD
Xray XRAY VLESS_XHTTP_TLS, VLESS_GRPC_TLS, VLESS_TCP_TLS, TROJAN_TLS, SHADOWSOCKS_XRAY, WIREGUARD_XRAY
MTProxy MTPROXY MTPROXY (Telemt)
Hybrid API Если у ноды задан agentBaseUrl, панель шлёт POST {agentBaseUrl}/v1/apply. Иначе — локальный apply через shared volumes (fallback для seed-ноды без URL).

Кому подходит

  • Один VPS с панелью и локальным прокси «из коробки»
  • Несколько серверов: панель отдельно, VPN-endpoint'ы на удалённых нодах
  • Своя выдача доступа, подписок и учёта без биллинга «из коробки»

Что дальше

  1. Установка — одна команда через install.sh или ручной Docker Compose
  2. Прокси-ноды — локальный и удалённый прокси
  3. Управление сервером — CLI overvpn
  4. Работа в панели — inbound'ы, пользователи, бэкапы
  5. Подписки клиентов — форматы и URL

Для разработчиков: архитектура, стек и локальная разработка — CONTRIBUTING.md в репозитории.

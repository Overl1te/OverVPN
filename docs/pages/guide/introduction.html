Введение

OverVPN — однонодовая панель управления VPN на базе sing-box. Она не маршрутизирует трафик сама: это control plane над одним VPN-ядром на одной машине.

Что умеет

Область Возможности
Протоколы Hysteria2, VLESS Reality, Trojan, Shadowsocks
Панель Пользователи, inbound'ы, планы, онлайн-сессии, аудит
Подписки JSON (sing-box), Clash Meta / Mihomo YAML, список ссылок, QR
Учёт Трафик, сроки, лимиты устройств и IP, автоматический enforce
Операции Apply конфига с rollback, бэкапы, Telegram-алерты

Интерфейс панели по умолчанию на русском; в шапке есть переключатель EN/RU.

Архитектура (упрощённо)

1. Администратор → HTTPS → Web-панель → API NestJS
2. API → PostgreSQL, Redis, sing-box (ядро)
3. VPN-клиенты → UDP/TCP → sing-box
4. Клиенты подписок → HTTPS → Subscription URL → API

Панель хранит желаемое состояние (пользователи, inbound'ы, assignments), рендерит конфиг ядра и применяет его атомарно. Клиенты получают профили через публичный subscription URL.

Важно Мульти-нода не поддерживается. Один сервер — одно ядро. Федерация, шардинг и «панель как прокси» вне скоупа проекта.

Кому подходит

  • Один VPS/VDS с Ubuntu или Debian
  • Нужна своя панель выдачи доступа без сложной инфраструктуры
  • Достаточно одного VPN-endpoint'а на машину

Что дальше

  1. Установка — одна команда через install.sh или ручной Docker Compose
  2. Управление сервером — CLI overvpn
  3. Работа в панели — inbound'ы, пользователи, бэкапы
  4. Подписки клиентов — форматы и URL

Для разработчиков: архитектура, стек и локальная разработка — CONTRIBUTING.md в репозитории.

Ограничения

1. Учёт трафика

Трафик — суммарный по пользователю, не «пользователь × inbound».

2. Онлайн-сессии

Идентификация устройства — best-effort (часто ip:порт).

3. Reload ядра

После reload счётчики stats пересоздаются; панель учитывает epoch/generation.

4. Статистика с нод

Часть воркеров трафика/онлайна ещё опирается на локальные пути ядра; полный сбор stats только через агент — в развитии. На удалённых нодах опирайтесь на heartbeat и статус apply.

5. Установщик

install.sh ориентирован на Ubuntu/Debian. Другие ОС — ручной Docker Compose.

6. Миграция со старых инсталлов

Инсталлы до модели «панель + ProxyServer / агент» не мигрируются in-place — только свежий install.

7. Лицензия

Вне скоупа

  • Мульти-тенантность / федерация панелей

  • Автоматический failover между нодами

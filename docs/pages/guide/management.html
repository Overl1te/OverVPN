Управление сервером

Вместе с панелью устанавливается CLI overvpn — обёртка над Docker Compose и Nginx.

Основные команды

overvpn status
overvpn logs
overvpn logs api
overvpn info
overvpn edit
overvpn restart
overvpn up
overvpn down

Обновление

overvpn update
overvpn update --build

Nginx и сертификаты

overvpn nginx
overvpn config set-domain --base-domain example.com --panel panel.example.com
overvpn config apply

Bootstrap владельца

overvpn bootstrap

Удаление

overvpn uninstall

Порты по умолчанию

Компонент Порт / доступ
Веб-панель 8000 / 443 через Nginx
API внутри Compose
PostgreSQL 5432 → 127.0.0.1
Redis 6379 → 127.0.0.1
VPN UDP 443
Внимание Не публикуйте Postgres, Redis и API напрямую в интернет.

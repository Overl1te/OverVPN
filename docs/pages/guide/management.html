Управление сервером

Вместе с панелью устанавливается CLI overvpn — обёртка над Docker Compose и Nginx. Без аргументов в терминале открывается консольное меню; ниже — те же действия командами.

Основные команды

overvpn  # интерактивное меню
overvpn status  # статус всех сервисов
overvpn logs  # логи всех контейнеров
overvpn logs api  # логи только API
overvpn info  # URL панели, подписок, учётка владельца
overvpn edit  # открыть .env
overvpn restart  # перезапуск стека
overvpn up  # запустить контейнеры
overvpn down  # остановить контейнеры

Обновление

overvpn update  # подтянуть образы из GHCR
overvpn update --build  # собрать образы локально на сервере

Nginx и сертификаты

overvpn nginx  # перегенерировать vhost'ы Nginx
overvpn config set-domain --base-domain example.com --panel panel.example.com  # сменить домены
overvpn config apply  # применить конфигурацию

Bootstrap владельца

overvpn bootstrap  # создать учётку владельца панели

Удаление

overvpn uninstall  # удалить OverVPN и данные установки

Порты по умолчанию

Компонент Порт / доступ
Веб-панель 8000 / 443 через Nginx
API внутри Compose
PostgreSQL 5432 → 127.0.0.1
Redis 6379 → 127.0.0.1
VPN UDP 443
Внимание Не публикуйте Postgres, Redis и API напрямую в интернет.

Диагностика

overvpn status  # контейнеры запущены?
overvpn logs api  # ошибки API
overvpn logs core  # ошибки sing-box

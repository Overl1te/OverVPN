Управление сервером

Вместе с панелью устанавливается CLI overvpn — обёртка над Docker Compose и Nginx. Без аргументов в терминале открывается консольное меню (навигация: стрелки ↑/↓ и Enter); ниже — те же действия командами.

Основные команды

overvpn  # интерактивное меню
overvpn status  # статус всех сервисов
overvpn logs  # логи всех контейнеров
overvpn logs api  # логи только API
overvpn logs agent  # логи агента (если proxy profile)
overvpn info  # URL панели, подписок, учётка владельца
overvpn edit  # открыть .env
overvpn enable-core singbox|xray|mtproxy  # доустановить ядро
overvpn disable-core singbox|xray|mtproxy  # отключить (если нет inbound'ов)
overvpn restart  # перезапуск стека
overvpn up  # запустить контейнеры
overvpn down  # остановить контейнеры

Обновление

overvpn check-update  # есть ли новый образ в GHCR
overvpn update  # подтянуть образы из GHCR
overvpn update --build  # собрать образы локально на сервере

Nginx и сертификаты

overvpn nginx  # перегенерировать vhost'ы Nginx
overvpn config set-domain --base-domain example.com --panel panel.example.com  # сменить домены
overvpn config apply  # применить конфигурацию

Bootstrap владельца

overvpn bootstrap  # создать учётку владельца панели

Удалённая нода

overvpn install-proxy --panel-url … --token … --node-id …  # на сервере прокси

Подробности — Прокси-ноды.

Удаление

overvpn uninstall  # удалить OverVPN и данные установки

Порты по умолчанию

Компонент Порт / доступ
Веб-панель 8000 / 443 через Nginx
API внутри Compose
Агент 7700 (на remote — снаружи для панели)
PostgreSQL 5432 → 127.0.0.1
Redis 6379 → 127.0.0.1
VPN UDP (Hysteria2) SING_BOX_UDP_PORT (443)
VPN TCP Reality / Trojan / SS / WG см. .env / README
Xray / MTProxy см. env
Внимание Не публикуйте Postgres, Redis и API напрямую в интернет. Порт агента на remote-ноде нужен панели для apply — ограничьте доступ firewall'ом по IP панели, если возможно.

Диагностика

overvpn status  # контейнеры запущены?
overvpn logs api  # ошибки API
overvpn logs agent  # регистрация / heartbeat / apply
overvpn logs core  # ошибки sing-box

Безопасность

Чеклист перед запуском

  • Все REPLACE_* заменены уникальными секретами
  • CORS_ORIGINS — точные origin'ы, без *
  • SUB_PUBLIC_BASE_URL — отдельный HTTPS
  • Postgres / Redis только на 127.0.0.1
  • Панель за reverse proxy с TLS
  • Владелец с сильным паролем + TOTP
  • Регулярные FULL бэкапы вне сервера
  • SWAGGER_ENABLED=false в проде
  • На remote-ноде порт агента (7700) не светить всему интернету — лучше restrict по IP панели

Секреты

Секрет Назначение
POSTGRES_PASSWORD БД
REDIS_PASSWORD Redis
JWT_ACCESS_SECRET Access JWT
SECRETS_MASTER_KEY Шифрование секретов и бэкапов
SING_BOX_CLASH_API_SECRET Clash API
NODE_TOKEN / INSTALL_TOKEN Аутентификация агента

Сетевая изоляция

Интернет → Nginx (443) → web → api
Интернет → UDP/TCP VPN-порты → ядра на ноде
Панель → TCP 7700 → агент (remote)
Postgres, Redis → 127.0.0.1

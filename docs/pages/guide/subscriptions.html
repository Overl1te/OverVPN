Подписки клиентов

Подписка — публичный HTTPS URL для скачивания профиля. Токен в URL — секрет.

Формат URL

Без пути в base URL:

https://sub.example.com/api/sub/{TOKEN}

С путём (SUB_PUBLIC_BASE_URL=https://example.com/sub):

https://example.com/sub/{TOKEN}

Форматы ответа

curl -o profile.json "$SUB_URL?format=sing-box"  # конфиг sing-box
curl -o links.txt "$SUB_URL?format=links"  # список ссылок
curl -o clash.yaml "$SUB_URL?format=clash"  # Clash Meta
curl "$SUB_URL/info"  # метаданные подписки

Брендинг подписки

Название подписки, announce, ссылки (Telegram / info), показ лимитов трафика, Happ Provider ID, info-блок (sub-info-*), уведомление об истечении (sub-expire*), fallback URL и тема (color-profile) настраиваются в плане. Расширенные Happ-поля активны только при указанном Provider ID. Имя подключения — шаблон на точке входа. Пустые поля оставляют дефолты (OverVPN - {username}, {identity} - {tag}).

Заголовки: subscription-userinfo, profile-update-interval, profile-title, опционально announce, support-url, profile-web-page-url, providerid, sub-info-*, sub-expire*, fallback-url, color-profile. Для ?format=links те же параметры дублируются строками #… в начале body (совместимость с Happ).

Расширенный UI Happ (кнопка в info-блоке, Renew, тема) обычно требует Provider ID с happ-proxy.com.

Ротация токена

  • В UI — Rotate subscription
  • API — POST /api/admin/users/:id/rotate-sub

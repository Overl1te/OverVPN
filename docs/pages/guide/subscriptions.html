Подписки клиентов

Подписка — публичный HTTPS URL для скачивания профиля. Токен в URL — секрет.

Формат URL

Без пути в base URL:

https://sub.example.com/api/sub/{TOKEN}

С путём (SUB_PUBLIC_BASE_URL=https://example.com/sub):

https://example.com/sub/{TOKEN}

Форматы ответа

curl -o profile.json "$SUB_URL?format=sing-box"
curl -o links.txt "$SUB_URL?format=links"
curl -o clash.yaml "$SUB_URL?format=clash"
curl "$SUB_URL/info"

Ротация токена

  • В UI — Rotate subscription
  • API — POST /api/admin/users/:id/rotate-sub

Rate limiting

Переменная По умолчанию
SUB_RATE_LIMIT_IP_LIMIT 60
SUB_RATE_LIMIT_TOKEN_LIMIT 120
SUB_RATE_LIMIT_WINDOW_SECONDS 60

Импорт в клиенты

Клиент Способ
sing-box Subscription URL или JSON
Clash Meta / Mihomo ?format=clash
Hiddify, Nekoray Subscription URL или links
QR Со страницы пользователя в панели

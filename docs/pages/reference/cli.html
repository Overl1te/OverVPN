CLI overvpn

Справочник команд CLI (/usr/local/bin/overvpn).

Синтаксис

overvpn <команда> [опции]

Жизненный цикл

overvpn install [опции]
overvpn up | down | restart
overvpn status
overvpn logs [service]
overvpn update [--build]
overvpn uninstall

Информация

overvpn info
overvpn edit
overvpn bootstrap
overvpn nginx

config

overvpn config show
overvpn config sync
overvpn config set-domain --base-domain example.com --panel panel.example.com
overvpn config nginx
overvpn config certs
overvpn config apply

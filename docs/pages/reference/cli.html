CLI overvpn

Справочник команд CLI (/usr/local/bin/overvpn).

Интерактивное меню

Без аргументов в TTY (или overvpn menu) открывается консольное меню: статус, info, логи, restart, update, edit .env, nginx, uninstall. -h / --help по-прежнему печатает текстовую справку. 

overvpn  # открыть меню управления
overvpn menu  # то же явно
overvpn --help  # текстовая справка

Синтаксис

overvpn <команда> [опции]  # общий формат вызова

Жизненный цикл

overvpn install [опции]  # установка Docker-стека, Nginx и TLS (консольный мастер)
overvpn up | down | restart  # запуск, остановка, перезапуск контейнеров
overvpn status  # статус сервисов Compose
overvpn logs [service]  # логи: api, web, core, postgres, redis…
overvpn update [--build]  # обновление образов (с локальной сборкой)
overvpn uninstall  # полное удаление OverVPN с сервера

Информация

overvpn info  # URL панели, подписок и bootstrap-учётка
overvpn edit  # редактировать .env
overvpn bootstrap  # создать или сбросить владельца
overvpn nginx  # перегенерировать конфиг Nginx

config

overvpn config show  # показать текущие домены и настройки
overvpn config sync  # подтянуть изменения из .install.conf
overvpn config set-domain --base-domain example.com --panel panel.example.com  # сменить домены
overvpn config nginx  # применить конфиг Nginx
overvpn config certs  # обновить сертификаты Let's Encrypt
overvpn config apply  # применить все изменения конфигурации

Файлы установки

Путь Назначение
/opt/overvpn/.env Runtime для Compose
/opt/overvpn/.install.conf Домены и TLS
/opt/overvpn/.credentials URL и bootstrap-учётка

Переменные окружения

Шаблон: .env.example. В проде: /opt/overvpn/.env.

Общие

Переменная По умолчанию Описание
NODE_ENV production Режим Node.js
LOG_LEVEL info Уровень логов
SWAGGER_ENABLED false OpenAPI UI
COMPOSE_PROFILES panel,proxy,singbox,xray,mtproxy Какие сервисы поднимать
CORS_ORIGINS — Точные origin'ы панели (без *)

База и кэш

Переменная Описание
POSTGRES_PASSWORD / DATABASE_URL PostgreSQL
REDIS_PASSWORD / REDIS_URL Redis

Аутентификация

Переменная Описание
BOOTSTRAP_ADMIN_USER / BOOTSTRAP_ADMIN_PASSWORD Первый OWNER
JWT_ACCESS_SECRET Подпись JWT
SECRETS_MASTER_KEY 64 hex, шифрование
SING_BOX_CLASH_API_SECRET Clash API

Агент и ноды

Переменная Описание
PANEL_URL URL панели для агента (co-located: http://api:3000)
NODE_ID UUID ProxyServer (локальный seed — см. .env.example)
NODE_TOKEN Bearer для API агента и вызовов панели
INSTALL_TOKEN Одноразовый токен register (remote install)
AGENT_BASE_URL Reachable URL агента для панели (http://agent:7700 или http://<ip>:7700)
AGENT_LISTEN / AGENT_PORT Слушатель агента (по умолчанию 7700)

Подписки

Переменная Описание
SUB_PUBLIC_BASE_URL Публичный HTTPS base URL
VPN_PUBLIC_HOST Дефолтный хост inbound'ов
SUB_RATE_LIMIT_* Rate limit подписок

Ядра и воркеры

Переменная По умолчанию
SING_BOX_ENABLED / XRAY_ENABLED / MTPROXY_ENABLED по профилям
SING_BOX_UDP_PORT 443
XRAY_LISTEN_PORT 8443 (9443 с Nginx)
MTPROXY_PORT_MIN–MAX 10001–10016
WORKERS_ENABLED true
BACKUP_ENCRYPT true

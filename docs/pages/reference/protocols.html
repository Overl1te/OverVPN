Протоколы

Четыре типа inbound'ов через sing-box.

Общие поля

Поле Описание
tag Идентификатор в конфиге
listen Адрес/порт на сервере
public host Хост для клиентов
port Обычно 443

Hysteria2

QUIC, хорош для нестабильных сетей. Нужен UDP на публичном порту.

hysteria2://PASSWORD@host:443/?sni=example.com&obfs=salamander#LABEL

VLESS + Reality

TCP с маскировкой под реальный TLS-сайт.

vless://UUID@host:443?security=reality&sni=...&flow=xtls-rprx-vision#LABEL

Trojan

TLS поверх TCP.

trojan://PASSWORD@host:443?security=tls&sni=example.com#LABEL

Shadowsocks 2022

Пароль клиента: SERVER_PASSWORD:USER_PASSWORD

Выбор протокола

Сценарий Рекомендация
Мобильные сети Hysteria2
Строгий DPI VLESS Reality
Старые клиенты Trojan
SS-клиенты Shadowsocks 2022

Firewall

ufw allow 443/tcp
ufw allow 443/udp

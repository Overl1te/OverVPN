Протоколы

Inbound'ы через sing-box и Xray.

Общие поля

Поле Описание
tag Идентификатор в конфиге
listen Адрес/порт на сервере
public host Хост для клиентов
port Опубликованный порт установки для протокола

Hysteria2

QUIC, хорош для нестабильных сетей. Нужен UDP на публичном порту.

hysteria2://PASSWORD@host:443/?sni=example.com&obfs=salamander#LABEL

VLESS + Reality

TCP с маскировкой под реальный TLS-сайт (sing-box).

vless://UUID@host:443?security=reality&sni=...&flow=xtls-rprx-vision#LABEL

Trojan

TLS поверх TCP.

trojan://PASSWORD@host:443?security=tls&sni=example.com#LABEL

Shadowsocks 2022

Пароль клиента: SERVER_PASSWORD:USER_PASSWORD

VLESS + xHTTP + TLS

Xray, TLS-сертификат (FILES). Порт: XRAY_LISTEN_PORT.

vless://UUID@host:8443?security=tls&type=xhttp&path=/&sni=example.com#LABEL

VLESS + gRPC + TLS

Xray, TLS-сертификат (FILES). Порт: XRAY_GRPC_PORT (по умолчанию 8446).

vless://UUID@host:8446?security=tls&type=grpc&serviceName=GunService&sni=example.com#LABEL

VLESS + TCP + TLS

Xray, классический TCP+TLS с опциональным xtls-rprx-vision. Порт: XRAY_TCP_TLS_PORT (по умолчанию 8447). 

vless://UUID@host:8447?security=tls&type=tcp&flow=xtls-rprx-vision&sni=example.com#LABEL

Trojan TLS (Xray)

Trojan на Xray с FILES TLS. Порт: XRAY_TROJAN_PORT (по умолчанию 8448 / 9448 с Nginx).

Shadowsocks (Xray)

2022-blake3 на Xray. Порт: XRAY_SS_PORT (по умолчанию 8449 / 9449 с Nginx).

WireGuard

UDP-туннель на sing-box (WIREGUARD, порт SING_BOX_WG_PORT = 51820) или Xray (WIREGUARD_XRAY, XRAY_WG_PORT = 51821). Ключи сервера и peer’ов выдаёт панель. В подписке надёжнее клиентский JSON sing-box / Clash; wg:// в links — best-effort. Per-user traffic stats могут быть ограничены возможностями ядра.

MTProxy

Telegram MTProto proxy на Telemt (MTPROXY). Порты MTPROXY_PORT_MIN–MTPROXY_PORT_MAX (по умолчанию TCP 10001–10016, до 16 inbound'ов). Ссылки выдаются только в панели (карточка пользователя) — в subscription formats (sing-box / clash / links) не попадают.

Выбор протокола

Сценарий Рекомендация
Мобильные сети Hysteria2
Строгий DPI VLESS Reality
CDN / HTTP-маскировка VLESS xHTTP TLS
HTTP/2 gRPC VLESS gRPC TLS
Простой TLS TCP VLESS TCP TLS / Trojan / Trojan TLS
SS-клиенты Shadowsocks 2022 (sing-box или Xray)
Нативный туннель WireGuard
Telegram MTProxy

Firewall

ufw allow 443/tcp  # HTTPS и TCP VPN
ufw allow 443/udp  # UDP VPN (Hysteria2 и др.)
ufw allow 8446/tcp # VLESS gRPC TLS (если используете)
ufw allow 8447/tcp # VLESS TCP TLS (если используете)
